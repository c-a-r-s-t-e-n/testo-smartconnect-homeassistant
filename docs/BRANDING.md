# Community branding

The thermometer, cloud and telemetry emblem is an original design for this community project. It is not Testo's corporate logo and does not imply manufacturer endorsement. Assets follow the repository's MIT license.

`brand/` contains 256/512 px icons and 1000×256/2000×512 px wordmarks, with light and dark variants. `docs/assets/header.png` is a 1600×480 px repository/Marketplace presentation header. The navy, orange and turquoise palette is designed to remain readable on both light and dark backgrounds.

To regenerate the assets, install Pillow and run `python scripts/build_branding.py`. The script uses DejaVu Sans fonts. Pillow is a development tool only and is not required by the integration.

For Marketplace icon delivery limitations and supported asset paths, see [Troubleshooting](TROUBLESHOOTING.md#missing-marketplace-icon).
